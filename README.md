# Warrior Companion (WoW: Forever)

Releases of Warrior Companion, a World of Warcraft: Forever add-on for warriors: combat alerts, a tank announcer, gear-set keybinds and professions help. This repo holds the release zips only.

## Install with WowUp (updates automatically)

1. In WowUp, select your **Forever** installation.
2. Go to **Get Addons → Install from URL**.
3. Paste `https://github.com/HdamaGIT/warrior-companion-releases` and install.

WowUp shows an update whenever a new release is published here.

## Install by hand

1. Close the game.
2. Download the latest `WarriorCompanion-vX.Y.Z-forever.zip` from [Releases](https://github.com/HdamaGIT/warrior-companion-releases/releases).
3. Extract it into `World of Warcraft\_forever_\Interface\AddOns\`. You should see four `WarriorCompanion*` folders directly inside `AddOns`.
4. Start the game, make sure the add-ons are ticked on the AddOns screen, and type `/wc`.

`WarriorCompanion` is the core and must be enabled. `_Combat`, `_Gearing` and `_Professions` are optional and work in any combination.
